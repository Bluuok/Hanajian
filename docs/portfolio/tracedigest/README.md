# 花笺 Hanajian · 个人网站展示素材

## 可直接使用的介绍

**标题**：把群聊里值得记住的讨论，轻轻收好。

**总述**：花笺是一款围绕群聊内容展开的话题整理工具。从一个想找回的话题出发，它将散落的讨论收拢成清晰的线索，并把每条重要信息连接回原始消息。柔和的纸面、薄荷绿和陪伴式插画，让回看群聊也成为一段轻松的探索。

**一句话流程**：选择群聊与话题 → 查看整理结果 → 对照关键证据与原始消息 → 回到聊天继续阅读。

**简短介绍点**：

- **从聊天中找到主题**：按群聊、关键词和时间范围，找到想重新了解的讨论。
- **让整理有出处**：摘要、关键证据与原始消息连在一起，读到哪里都能回头核对。
- **让信息更愿意被打开**：插画、轻盈色块和清晰的阅读顺序，让密集的聊天内容更容易靠近。
