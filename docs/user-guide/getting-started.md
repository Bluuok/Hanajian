# 第一次使用花笺

内容收藏可以直接使用公开链接；整理微信群聊需要先连接你有权访问的本机微信数据。

## 启动应用

使用本项目提供的安装包，或按[开发说明](../development/overview.md)在本机启动。安装包发布入口为 [Hanajian Releases](https://github.com/Bluuok/Hanajian/releases)，平台与文件名以实际发布内容为准。

启动后，连接页会显示当前系统的连接方式、数据目录和状态。如果暂时只需要保存抖音或小红书公开内容，可以点击“先打开内容收藏”，不需要连接微信。

## 连接已有微信数据

1. 确认连接页上的数据目录属于你要使用的账号。
2. 按当前页面提示提供对应的数据库密钥或完成已有连接流程；已保存的有效连接可继续使用。
3. 连接后检查账号与群聊列表，打开一个群聊确认历史消息可读取。

密钥获取和数据库访问受微信版本、系统权限与所选连接方式影响。手动获取密钥可能涉及微信进程访问；更完整的边界见[隐私说明](./privacy.md)。本次功能升级不改变已有数据库连接方式。不要为排障反复删除数据或密钥；先查看[连接问题排查](./troubleshooting.md)。

## 配置模型并总结

在“设置”中配置并测试 AI 模型，再打开“问问 AI”，选择一个群聊并输入问题，例如：

- “总结最近 1000 条消息”。
- “总结今天下午讨论的发布问题”。
- “整理这个群里某位成员最近的发言”。

最近消息按指定数量从数据库分页读取，最多支持 5000 条。回答只显示在本机；需要其他群聊时，先在界面切换群聊。“助手设置”可调整总结要求并查看运行日志。

## 核对并保存知识笔记

勾选“提取专业记忆”，设置要保留或排除的内容，可选择笔记格式和表达风格。选择本机目录后提问，核对生成的草稿，再点击“写入记忆库”。未确认的草稿不会自动写入。详见[知识笔记](./local-notes.md)。

话题工作台可以按关键词、成员和时间整理原文、保存结果并设置本地每日订阅。定时任务需要应用运行；结果只保存在本机。

## 收藏平台内容

打开“内容收藏”，粘贴抖音或小红书分享文案或公开链接，解析并预览后选择保存目录。保存媒体后，可以生成带普通 Markdown 超链接或 Obsidian 双链的笔记。默认不导入 Cookie，不新增平台账号登录；水印状态以解析结果为准。详见[内容收藏](./platform-integration.md)。

## 数据与隐私

本机数据库解析与索引保留在本机。使用远程模型时，本次问题所需的聊天上下文和提取要求会发送给你配置的服务；平台解析与下载会访问对应平台。桌面总结不登录微信机器人，也不发送微信消息。详细说明见[数据、隐私与安全](./privacy.md)。
