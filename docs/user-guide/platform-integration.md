# 收藏抖音和小红书内容

打开“内容收藏”，粘贴完整分享文案或公开作品链接，再点击“解析与预览”。未连接微信时，也可以从连接页面选择“先打开内容收藏”。支持抖音、小红书的图文和视频作品。

先检查标题、作者、资源数量、原始链接与水印状态，再保存单个资源或全部资源。应用只解析平台页面及对应媒体域名；网页请求失败时，会尝试使用已安装的 Edge、Chrome 或 Playwright Chromium。浏览器使用独立临时会话，不导入个人浏览器资料、Cookie 或新的登录凭据；登录限制、安全验证或已失效作品会显示失败原因。

媒体源明确标注无水印时显示“平台标明无水印”；不能确认时显示“水印状态未知”。本功能选择平台提供的媒体资源，不执行后期去水印，不保证所有作品均可获取无水印版本。

选好内容保存目录后，点击“保存全部图片”“保存视频”或单项保存。保存成功后才能“写入 MD”；程序只链接成功保存的文件，不生成指向尚未下载资源的链接。重复保存会核对文件并复用，遇到同名文件或已有手工修改时保留原文件。

笔记支持两种链接格式：

- Markdown 超链接：默认选项。使用笔记目录到媒体文件的相对路径；不同磁盘使用文件链接，适合普通 Markdown 编辑器。
- Obsidian 双链：媒体需要与笔记放在同一个仓库内。应用从笔记所在目录向上查找 `.obsidian`；未找到时以笔记目录为根。

笔记保留标题、作者、原始作品链接、本地媒体链接及水印状态。选择保存目录只影响后续操作，不会移动已有文件。处理和下载会访问所选平台，不调用第三方解析服务，也不向微信发送消息。
