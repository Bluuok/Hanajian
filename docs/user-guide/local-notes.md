# 把讨论整理成知识笔记

在“问问 AI”选择一个群聊，输入需要总结的范围，例如“总结最近 1000 条消息”。消息从已连接的本机数据库读取，不受当前聊天窗口已加载条数限制。单次最多 5000 条；更大的范围请分段提问。

勾选“提取专业记忆”，填写“想沉淀什么”，可说明保留的领域、排除的内容和需要的细节。默认要求保留结论、方法、依据、待验证问题和资源，排除闲聊与个人联系方式。筛选由模型执行，写入前仍需核对。

“笔记格式”可选择知识笔记或决定与行动。“表达风格”可填写简短条目、解释术语、保留操作步骤等要求。总结本身的重点与篇幅可在“助手设置”调整。

选择本机保存目录后再提问。总结完成时只显示草稿；点击“写入记忆库”才生成 UTF-8 Markdown 文件，也可以选择“不写入”。每条笔记内容须引用真实输入消息，发言人和时间由程序回填；不存在的来源或不符合格式的结果会被拒绝，模型最多重写一次。

草稿与最终文件包含相同正文、来源群聊、生成时间、来源消息数量、提取要求及表达要求。写入使用新文件名，不覆盖已有笔记；可保存到普通文件夹或 Obsidian 仓库。专业记忆笔记与聊天检索索引是两项能力，写入 Markdown 不会自动加入聊天索引。

对话历史按微信数据目录隔离。处理过程中切换账号或断开数据库会丢弃本次回答。每日话题订阅在本机保存结果，不需要机器人账号；应用运行时检查到期任务，支持最多七天的有限补跑。

使用远程模型时，问题、已读取的消息和提取要求会发送给所配置的服务。使用本机模型可使这一路径留在本机。不会为此登录微信机器人或发送微信消息；数据库连接与密钥获取仍受微信版本、系统权限和连接方式影响。
