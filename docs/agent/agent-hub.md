# 本机“问问 AI”

AI 助手在花笺桌面端按需读取已连接的本机聊天记录，回答与草稿显示在应用内。

## 使用方式

1. 连接自己的本机微信数据库。
2. 在“设置 → AI 模型”配置并测试模型。
3. 打开“问问 AI”，从左侧选择群聊。
4. 在中间查看原始群聊，在右侧输入总结问题。

可用问题示例：

- “总结这个群最近 100 条消息”；
- “总结这个群今天下午的消息”；
- “总结这个群里张三最近的发言”。

## 提示词与日志

一级导航中的“助手设置”提供两项能力：

- 自定义总结指令：调整答案重点、结构、篇幅和表达；
- AI 运行日志：查看只读工具调用与错误信息，可筛选、复制和清空。

自定义指令不能覆盖内置只读边界。AI 可使用群聊匹配、群成员匹配、历史消息读取和公开平台分享解析工具。文件保存通过界面按钮确认。

## 专业记忆

勾选“提取专业记忆”后，在“想沉淀什么”中填写要保留的领域与内容，并选择本机保存目录。总结完成后，助手按这些要求从本次已读取的消息中筛选、整理草稿。若不希望沉淀某类信息，请在提取要求中写明。

草稿预览与最终文件使用同一套排版。只有用户点击“写入记忆库”才会保存，不会自动写入。每次确认生成一个 UTF-8 Markdown 文件，包含：

1. 结论与方法：编号、加粗标题、正文；
2. 关键依据：原话或事实及其解释；
3. 待验证事项：尚未确认的问题；
4. 关键词：技术名词、模型、框架、工具及原文网址。

每条内容的来源均与正文空行分隔，发言人和时间通过真实消息 ID 回填。没有相关内容的分区保留标题并标明暂无内容。文件末尾附来源群聊、群聊 ID、草稿 ID、生成时间、沉淀来源消息数量和提取要求；数量统计的是四个分区引用的去重消息数。

开发时，默认模板定义在 `src/shared/agent-memory-format.ts`。分区定义、提示词生成、结构校验、Markdown 排版和导出标识与提取服务分离，新增模板无需在提取服务中增加分区分支。可以在提取区域选择笔记格式和表达风格。对不符合模板或引用不存在消息 ID 的模型输出，程序携带校验错误和原始提示词要求重写一次；再次失败则不生成可写入草稿。

## 图片和表情包

“问问 AI”不读取或解析普通微信图片，图片消息仅以“[图片]”参与上下文；文字浏览和总结不受影响。

微信 4 的自定义表情包缓存也可能是 AES 密文。花笺会使用该条消息自带的 AES 密钥在本机解密；如果旧消息缺少密钥或本机没有缓存，会在消息气泡中显示具体失败原因。

详细步骤见[知识笔记](../user-guide/local-notes.md)。
