# 首页设计资产

`src/renderer/src/assets/illustrations/recorder-hero.png` 是本轮通过内置 ImageGen 生成的独立透明人物资产（1024×1536，RGBA），用于首页 Hero。与已确认的二维 Q 版陪伴人偶分开；不替换人偶外观或跟随逻辑。

生成要求：正常成年二次元人物比例，棕色短发、琥珀眼睛、灰粉小发结、雾蓝绿开衫与奶白内搭、抱粉色笔记本；精细线稿与柔和水彩/赛璐璐质感，朝页面内容一侧微转，透明背景，无文字、边框或装饰面板。主插画独立于页面布局与装饰层，不能用整页背景图代替真实业务组件。

用户最新决定优先于附件旧条款：全页面保留无框跟随人偶；应用只提供白色主题，移除深色与跟随系统选择，并兼容已有设置。

assets/decor 下的 petals、stars、leaves、paperclip 和 book-plant SVG 为本轮独立装饰文件；图标由组件内 SVG 绘制，不依赖整页截图。用户参考图仅在验证文档中用于对照，不加载为产品背景。现有人偶来源与许可说明沿用 docs/companion-gaze.md。
