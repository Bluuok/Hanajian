# 首页改造验收记录

范围：PR #3 与用户附件的首页、话题链路改造。计划原文保存在 docs/plans/2026-09-22-topic-home-visual-completion.md，来源提交 9275dcfe9d4c063f2df27babe5bcc6590fbe0234。用户后续决定优先：人偶全页面无框；应用固定白色主题。

| 要求 | 实现与验证 |
| --- | --- |
| 插画与构图 | 独立透明正常比例插画、SVG 装饰；Hero 跨到薄荷摘要卡；装饰不接收鼠标事件。小于 860px 隐藏大插画，标题保持一行。 |
| 筛选与组件拆分 | 关键词、快捷日期、高级别名/排除/成员；独立状态 hooks、摘要、证据、原文、空态/加载态与订阅抽屉。 |
| 元数据真实性 | 不添加无来源的分类数量、点赞和关联话题；相关话题显示明确空态，测试接口同样关闭尚不可用能力。 |
| 原文联动 | 查看原文读取本机完整记录；在聊天中定位先验证 locator，再读目标秒的原始 Message，按完整 ID 高亮。缺失/歧义/超限均报错，不用摘录拼消息、不按 localId 或相近时间替代。 |
| 作用域隔离 | 话题状态以账号与连接状态重建；原文导航在每次 await 后检查连接代次和导航序号。切群/切页/新查询取消旧导航；返回最新消息重新读取当前群。 |
| 人工修改与导出 | 切换证据不重置勾选；修改后结论失效；导出保留旧 TopicEvidence 字段并丢弃失效 claims。 |
| 订阅 | 抽屉保留创建、启停、历史、载入旧包与重试；运行全部仅执行当前群已启用订阅。Escape 关闭并恢复焦点，Tab 限制在抽屉内。 |
| 图片密钥引导 | 连接后检查当前账号图片密钥，缺失或检查异常时给出设置入口；聊天图片因密钥缺失报错可直达同一设置页。设置页列明自动获取、验证、保存步骤；未自动读取真实微信密钥。 |
| 白色主题 | 设置入口移除深色/系统选择；旧配置读取、保存归一化；HTML 首帧即 light，退出工作区也保留 light。 |
| 全页面伙伴 | 沿用已确认二维头眼跟随实现与原图，本轮无修改；真实 Electron 检查透明角、指针跟随、页面切换、缩小与降级。 |
| TopicPackage / 时间 | 后端统一投影结构化包；首页、旧话题面板与订阅使用北京时间闭区间。 |
| 召回、核对与诊断 | 零词面召回时受控扩展最多 5 个词；稳定证据 ID；大上下文最多 8 批两轮核对并做全局核对，超限保留候选不发布中间结论。 |
| 缓存与错误 | 账号/数据库作用域隔离、并发合并、30 秒缓存/12 条上限、副本返回；AI 失败不缓存，定位返回类型化错误。 |

验证：相关单元 52 项（43 项话题/设置 + 9 项原文导航）；主页/外观/旧话题组件 13 项；原话题/伙伴 Electron 11 项，图片密钥引导 Electron 2 项；node/web 类型检查、改动文件 ESLint 与 electron-vite 构建通过。最终截图与命令见 [验证记录](verification/README.md)，可打开 [前后对照](verification/compare.html)。

截图使用合成数据。1073×668 窗口首屏可见第一条证据与原文卡，完整列表及按钮可能需要向下滚动；不宣称所有内容完整铺在首屏。Windows 截图有 1px 取整误差。DPR=2 是 Chromium 仿真，125% 是 CSS zoom，均不等同于多硬件缩放实测。macOS 图片基线没有在本机重新验证。

真实微信读写、实际图片密钥获取、真实模型相关性、订阅真实投递及 Windows 安装包发布均未验证。实现分支提交到 GitHub 供审阅，不自动合并规划 PR 或实现 PR。
