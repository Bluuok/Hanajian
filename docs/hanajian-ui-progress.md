# 花笺 Hanajian · 界面实施记录

2026-09-22 更新：按用户新要求，聊天静态伙伴已替换为已确认的原图头眼跟随效果，所有页面左下角均显示，保留收起偏好；外框和原图背景通过透明画布与轮廓遮罩移除。该二维方案取代此前的 VRM / Live2D 人偶计划；详见 [全页面伙伴接入说明](companion-gaze.md)。以下为 PR #2 的历史实施记录。

本轮按 PR #1 的界面提案实现，应用显示品牌确定为「花笺 Hanajian」。GitHub 仓库地址、package name、应用安装身份和已有数据目录保持兼容。

## 已实现

- 用户确认显示名称「花笺 Hanajian」；灰粉花朵与雾蓝信笺图标同步覆盖 SVG、PNG、ICO、ICNS，安装包显示名称同步更新。

- 独立话题首页与明确的聊天工作区入口；展开品牌导航，窄窗折叠。
- 浅色主题采用暖白、雾蓝和灰粉语义配色，保留深色与跟随系统设置。
- 复用真实 TopicPanel 查询、生成、证据失效、导出和订阅逻辑。
- 话题筛选、结果和已选来源在进入聊天再返回后保留；切群重新挂载面板，隔离旧群结果。
- 候选证据与消息来源摘录并排联动，明确显示消息 ID；不把摘录视作历史消息精确跳转。
- 首页右上使用用户提供的角色完整 PNG；聊天工作区左下使用同图的静态备用形态，位置在导航预留区，可关闭并记住选择。
- 删除全局 SVG 人偶、越界眼球和指针跟随监听；其他页面不显示小人偶。
- 修复窄聊天栏状态文字竖排，以及窄窗首页入口被裁切。
