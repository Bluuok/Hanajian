# TraceDigest「话题整理」视觉样板

本样板由 OpenDesign 的 Local Codex 路线生成。生成任务在最终交付前遇到本地服务重启并报告失败；这里保存的是已落盘的产物，随后独立验证了 HTML、人物素材加载、证据切换与三档浏览器截图。截图属于固定样板数据，不代表真实聊天结果。

## 视觉来源与基准

- 参考图：用户提供的 1698×1066 截图。暖白纸面、淡薄荷摘要、雾蓝原始消息、灰粉主操作与左侧双栏来自该图。
- 人物：本轮根据用户参考图生成的透明插画，原始尺寸 1086×1448，RGBA 格式；仓库文件位于 `src/renderer/src/assets/hanajian/hero/topic-recorder-scene.png`。
- 下列六个基础色由参考截图取样 RGB 后换算为 OKLch。其余状态色从同一色相关系调整明度与彩度；没有使用整页位图。

## 观察到的视觉规则

1. 左侧主导航与群组栏是连续的浅色纸面；内容使用细边框分区，不使用厚重阴影。
2. 标题、筛选、摘要与人物处于同一舞台；人物紧靠薄荷摘要，底缘止于证据区上方。
3. 灰粉是唯一高饱和操作色，只用于主要操作与少量状态强调。
4. 信息自上而下连接：筛选 → 摘要 → 三条证据 → 当前原文 → 相关话题；摘要的浅绿与原文的雾蓝帮助分辨层次。
5. 左下伙伴区域维持独立、可读的矩形留白，没有书本或植物覆盖。

## 布局与响应式

| 视口 | 布局 |
| --- | --- |
| 1698×1066 | 220px 主导航 + 266px 群组栏；人物约 398px 高；证据与原文并排。 |
| 1280×800 | 主导航缩为 76px 图标栏，群组栏 212px；人物约 375px 高；主区域保留双列。 |
| 1073×668 | 主导航 66px，群组栏 190px；人物约 330px 高；生成按钮换行进独立控制行，证据与原文仍并排。 |
| 860px 以下 | 群组栏收起，证据与原文上下排列。 |
| 600px 以下 | 顶部图标导航，人物缩入标题区，控件与摘要按单列优先级排列；无横向滚动。 |

桌面外壳占满视口，主阅读区独立纵向滚动；较短的 800px/668px 窗口可继续向下阅读相关话题。所有业务文字和控件均为 HTML。证据按钮切换原文；搜索、类别、群组和日期只在固定样板数据内工作。生成与其他页面入口明确提示尚未接入真实服务。

## 移植要点

- 仓库入口文件：`index.html`。CSS 与 JS 都内嵌，图像使用指向仓库素材的相对路径。OpenDesign 中的原始入口是 `topic-home.html`。
- 分区标记：`data-od-id` 标出导航、舞台、控件、摘要、证据、原文与相关话题。
- 固定样板消息在脚本 `messages` 数组；移植到 React 时可改为 props/state，保留证据索引与当前原文的映射。
- 本页不调用真实 TraceDigest API、群聊、模型或账号服务；样板文字均不是实际聊天记录。

## 仓库接入

实际首页沿用应用已有导航、群组列表、左下伙伴和话题业务状态；共享构图区由 `TopicsHomePage.tsx` 与 `topics-home.scss` 实现。人物、书本植物是独立透明素材，搜索、时间、生成、证据、原文、导出仍使用 React 组件。真实数据渲染的 1073/1280/1440 宽度截图保存在 `docs/verification/homepage-after/`；本目录截图只作为固定样板数据的视觉基线。
