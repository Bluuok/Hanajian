# 话题整理与每日订阅

在“问问 AI”选择群聊，点击右上角“话题”。输入话题、别名、排除词和可选成员微信 ID，选择精确到秒的开始及结束时间，再点击“生成话题包”。手动时间按界面显示的本机时区解释，范围包含两端；单次最多 31 天。

话题包展示来源群、扫描数量、候选原文、入选原因、AI 结论及证据按钮。点击证据按钮在面板内定位原文。可以改选候选；改选立即使旧摘要失效，导出时清除旧结论。JSON 通过本地下载导出，不创建公开链接。原文不写入问问 AI 的 localStorage 对话历史。

## 检索和判断的实际边界

- 关键词与别名召回，补充前后各三条、十分钟内上下文，以及明确匹配的引用。相邻消息只是候选，还需模型复核。不是完整语义检索；换一种完全不同的说法仍可能漏检。
- 服务端强制群、时间及成员 ID 范围。成员筛选是严格范围，其他成员的回答也不会加入；需要完整问答时留空成员条件。
- 最多扫描最近 10,000 条、保留最近 300 个候选；达到上限明确标记不完整。过长原文不截尾；超过模型上下文预算时仅显示原文，不产生摘要。
- 同一已配置模型分别执行提取与核对，每项结论必须引用本次候选中的有效 ID。第二次模型请求是独立提示上下文，不代表跨模型审查，也不能保证语义判断永远正确。
- 模型失败或证据 ID 无效时保留候选，不显示未经核对的初稿。图片、语音等仅利用现有文本/转写，缺失媒体识别会显示提示。
- 微信自然语言入口可以调用相同的 `build_topic_bundle` 只读工具。没有读取到原文时不输出事实性总结；群名歧义返回候选要求确认。
- 使用远程 AI 配置时，候选原文会发送给该供应商。本机优先不等于离线模型。

## 每日 craft 任务

连接本机数据库后，在群列表确认“helson 的 agent 学习群”的实际群 ID。订阅面板默认为 `craft`，每天北京时间 08:00 整理前一天 00:00:00–23:59:59，保存前请核对当前群。收件人固定为 Clawbot 已连接的本人账号，由主进程验证；模型不能修改。

订阅按微信数据库账号目录隔离并原子保存；应用运行且数据库连接时，每分钟检查到期窗口。启动/唤醒后最多补跑近七天，每次三个窗口；不会自动回放七天以前的记录。失败或中断窗口需要手动重试，重试使用该任务保存的原始时间及查询条件。可以暂停/继续。最近 200 次状态保留，最近 20 个任务保留完整话题包，可查看并导出。去重回执独立于界面历史保存，重启或历史轮换不会导致重复自动运行。

**目前原生微信合并转发尚不可用。** 连接器的发送类型没有合并聊天记录。本轮提供明确的能力状态和阻塞原因，定时生成的话题包保存在本机；不会发送文字、长图或公开链接冒充合并转发。原生发送与接收端验证仍需后续具备相应能力的连接器。

当前电脑尚未连接微信数据库，真实订阅尚未创建/启用。只有确认群 ID、连接状态和固定收件人后才保存实际订阅。

## 微信连接与验证

本机历史数据库读取和 Clawbot 扫码是两条链路，扫码本身不能获得群历史。Windows 自动获取数据库密钥涉及微信进程 hook/内存访问；不能保证第三方工具不存在账号限制风险。本次开发没有触发自动密钥获取、读取微信进程或真实微信发送。已有密钥应只在应用中填写，不粘贴到聊天、日志或 GitHub。

测试使用合成聊天数据和隔离 Electron 用户目录。它们验证范围、分页、证据结构、订阅恢复及 UI，不证明真实微信发送可用，也不替代人工标注样本的相关性评估。
